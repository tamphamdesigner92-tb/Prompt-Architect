Thêm nhiều key để tự luân phiên: sau mỗi 10 lượt gợi ý hoặc khi key không phản hồi, ứng dụng tự chuyển sang key kế tiếp. Lấy key miễn phí tại aistudio.google.com
    Key báo lỗi hoặc bị từ chối? Xem cách xử lý

    Google đã siết quy định về API key: từ 19/06/2026 các key gắn nhãn Unrestricted bị từ chối, và từ tháng 9/2026 Standard key bị bỏ hẳn, thay bằng auth key.

    Cách sửa nhanh (khoảng 30 giây mỗi key):

    1. Mở aistudio.google.com/apikey
    2. Tìm key đang gắn nhãn Unrestricted, rê chuột vào nhãn đó rồi bấm Add restrictions
    3. Chọn Restrict to Gemini API only và xác nhận

    Hoặc bấm Create API key để tạo key mới (key mới tự động là auth key), rồi dán vào ô phía trên và xoá key cũ.

    Bấm Kiểm tra tất cả sau khi làm xong để xác nhận key đã dùng được.
